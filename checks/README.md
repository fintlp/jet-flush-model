# Checks

Deterministic scripts behind the figures quoted in the model description. Run them from the repository root with Node.js 18 or later. Each script uses a fixed seed, so the numbers are the same on every run; the random designs are drawn uniformly over the simulator's slider ranges, as described in `lib.js`.

To compare with the released model, first get its code:

```bash
git fetch origin main
git show origin/main:model.js > /tmp/model-main.js
```

| Script | What it checks |
|---|---|
| `node checks/regression.js /tmp/model-main.js` | All results except noise are identical to the other model version. Exits with code 1 on any difference. The wall film changed in 2.0, so against a 1.x model this check fails by design; it is for comparing versions that should agree. |
| `node checks/physics.js` | Physics checks with pass limits, 59 checks, about six minutes. A: energy and angular momentum of a frictionless film, water balance, physical ranges of all state variables, smoothness of peak swirl and of the main results under small design changes (large steps are refined 10 and 100 times and rerun at 2 ms, to tell jumps, steep slopes and time-step jitter apart). B: closed-form cases (cistern drain, steady pool level at constant inflow, level table, film on a vertical cylinder, paper removal). C: the pool level and pool swirl equations re-integrated with fourth-order Runge-Kutta at a 20 times finer step. D: checks proposed by the independent physics review (spatial convergence, siphon break, time step down to 1 ms, partial flush head, film front, monotone waste trends, round-bowl symmetry, rim line depth), and that the noise calibration's evaluation equals the simulator's. A check tied to a documented open issue is reported as KNOWN and does not fail the run, except with `--strict`, which is meant for releases. These checks show that the model solves its own equations correctly, not that the equations describe a real bowl. |
| `node checks/pinn.js` | The physics-informed network (pinn-core.js): from a flush simulated with a weir coefficient of 1.45, read 81 or 13 times with noise, the network and least squares both find it within 6 %; training is deterministic; with the record cut at 3 s the physics keeps the later level closer to the truth than the same network without physics. About 5 seconds. |
| `node checks/challenge.js` | The engineering challenge (challenge-core.js): recomputes the eight races the page shows and compares them with `challenge-data.js`; also the start misses the targets, race #1 (AI route fewer runs than the classic route), valid designs on slider steps, no repeated runs, determinism. About three minutes; `--quick` race #1 only; `--write` regenerates `challenge-data.js` after a change to the model or the core. |
| `node checks/literature.js` | The presets against figures from published toilet studies, patents and test reports (sources page, sections 1 and 5), about 12 seconds. RANGE checks (peak and mean flush flow, trap diameter) are backed by more than one source and fail the run when outside. COMPARE lines (film turns on the wall, water held in the bowl, water at rest, start of outflow, wall shear, best trap diameter, siphon peak flow, peak flow over random designs) come from a single source or a figure defined differently from the model's; they give a verdict and a reason and never fail the run. This is a plausibility check, not a validation. |
| `node checks/resolution.js` | How much cleaning, rim line and noise depend on how often the jet films are retraced: simulator and coarse settings against retracing at every step, including the short, strong flush that was the worst case in 1.3 (section 11). Takes about two minutes. |
| `node checks/timestep.js` | How much results change when the time step is halved (section 11) |
| `node checks/presets.js` | Preset figures quoted in section 10: vortex dips, margins, air core and siphon break times, source shares, Gordon cross-check, siphonic against washdown |
| `node checks/noise-range.js` | Width of the sampled noise range, and interior coefficient values outside the corner range (section 10) |
| `node checks/timing.js /tmp/model-main.js` | Run time against the other model version; the quoted overhead is the ratio (section 11) |
| `node checks/browser.js` | The simulator page in a headless browser: presets and trap type, the 25 mm rim gap in sliders and sweep, undo and Demo me history, pinned reference, AI lab details, the noise calibration (A-weighting of test tones, the demo fit, a generated WAV file, meter readings), the tolerance study, the robust optimiser search, the progress bar with Cancel and Stop, the engineering challenge with its live recomputation and guided tour, the CFD check, the physics-informed network and the three-part story (70 checks, about eight minutes). Needs Playwright: `npm install --no-save playwright && npx playwright install chromium`. Exits with code 1 on any failure. |
